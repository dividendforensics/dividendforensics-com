BreakBefore · Beta · Not yet publicly released

Pre-release static inspection for packaged game builds.

BreakBefore reads packaged game builds without launching them and checks for release-package problems such as exposed secrets and API keys, development or debug leftovers that should not ship, and packaging mistakes.

Principle

If BreakBefore cannot inspect something, it reports that limitation instead of silently passing it.

Status

In development. Not yet publicly released.

BreakBefore is currently focused on Godot 4.x builds.

It is read-only: it does not launch the game, modify the build, or make network requests.

BreakBefore is a developer-tool project from Dividend Forensics Bureau.

Developed with Claude Code as part of the engineering workflow.

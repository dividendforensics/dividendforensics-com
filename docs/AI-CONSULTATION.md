## 목표와 현재 구현

기존 `dividendforensics.com`을 무료 리츠 교육·계산기 사이트로 확장하고, 당분간 애드센스를 통한 수익화를 준비한다. 2027년 멤버십 구상은 별도이며 현재 가입·결제는 열지 않는다. 기존 Benzinga 연구 기록과 저자 정보, 문의 경로는 유지한다.

구현은 정적 HTML/CSS/JavaScript와 Python 빌더다. `content/`에 교육 원고, `education.py`에 페이지 생성, `curriculum.py`에 초급·중급·고급·전문가 경로, `calculators.js`에 계산식이 있다. 전문가 4편을 포함한 교육 36편, 계산기 7개, 4개 단계별 경로와 확인 문제, 용어 25개, GPT 설명 이미지 4개가 대상이다. 이미지 원본은 로컬 `img/education/originals/`, 웹 배포본은 같은 상위 폴더의 WebP다.

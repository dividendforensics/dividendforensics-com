# DFB 교육 페이지 읽기 구조 개편 — 2026-10-18

## 요청과 구현
모든 수업이 같은 템플릿을 복제한 것처럼 보이는 문제를 줄이기 위해 주제별 문서 구조를 적용했다. 브랜드 색상, 공통 메뉴, URL, canonical, hreflang, 발행일과 검토된 원고는 유지했다. 새 실사례나 투자 판단을 추가한 작업이 아니다.

영어 52편 + 스페인어 4편에 적용했다. 영어 분포:
- 개념 에세이 5편: 도입 설명을 크게 읽고 개념을 순서대로 이해.
- 사업 현장 노트 12편: 첫 설명 이후 사업 관점들을 나란히 읽고 주의점과 공시 체크를 함께 검토.
- 계산 노트 17편: 정의 다음에 계산 예제를 배치하고 해석을 이어 읽음.
- 위험 브리핑 7편: 짧은 질문 제목과 분석 본문을 대응시키고 주의점·확인 항목을 앞에서 제시.
- 공시 읽기 순서 3편: 번호가 있는 연속 단계로 자료를 따라 읽음.
- 연구 워크숍 8편: PR9에서는 완료된 결과 사례가 선행 지식·가정보다 먼저 배치됐다. 독립 검토 지적에 따라 후속 수정에서는 선행 지식·가정 → 분석 → 검산 결과 → 실습 순서로 바로잡았다.

같은 도해를 모든 REIT 글의 첫 화면에 반복하지 않는다. 부동산 입문·유형 글에는 설명에 필요한 기존 도해를 유지한다. FFO/AFFO/NAV/payout/BDC NII/PIK 6편은 기존 가상 예제의 수치만 요약한 HTML 숫자 패널을 추가했다. 실시간 기업 수치나 위험 점수가 아니다. 퀴즈와 정답 해설, 출처, 주의사항은 삭제하지 않았다.

## 다른 AI에게 전달할 검토 요청
공개 배포 커밋을 먼저 확인한 뒤 위 여섯 대표 페이지와 스페인어 원문 대응 페이지를 확인해 주세요. 같은 색상만 바꾼 것이 아니라 내용별 읽는 순서·폭·문단 배치가 달라졌는지, 과한 장식이나 새 혼란이 생겼는지 평가해 주세요.

1. FFO는 정의→계산→해석, 전문가 과정은 선행 지식→사례→분석 순서가 적절한가?
2. 숫자 패널은 바로 아래 원문 예제와 단위·기간·분모·반올림이 일치하는가? 가상 예제가 실제 기업 자료처럼 보이지 않는가?
3. 원고·표·출처·주의사항·퀴즈가 누락되거나 다른 주제에 잘못 배치되지 않았는가?
4. 320/390px에서 표와 숫자, 긴 제목, 단계 번호가 잘리거나 가로 넘침을 만들지 않는가?
5. 목차 순서와 실제 읽기 순서, 키보드 이동, JavaScript 없는 읽기가 유지되는가?
6. URL·canonical·hreflang·원래 발행일·AdSense 확인 정보가 유지되는가?

문제마다 심각도, URL/파일, 관찰한 내용, 재현 절차, 수정안을 적어 주세요. 실제 실행하지 않은 검사를 실행했다고 적지 말고, 이전 검수 수치를 이번 검수에 합산하지 마세요. 순위·승인 효과는 측정하지 않았습니다.

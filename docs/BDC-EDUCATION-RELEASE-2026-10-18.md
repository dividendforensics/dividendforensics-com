# BDC 학습실 확장 — 2026-10-18

## 목적과 구현 범위

기존 사이트는 REIT 교육36편과 BDC 계산기5개가 있었지만, BDC를 순서대로 배우는 독립 과정이 없었다. 이번 변경은 BDC 교육16편·4단계 과정·검색 가능한 학습실·BDC 용어집14개를 추가한다. REIT 원고36편과 과정은 별도로 유지한다. 계산기 수는15개로 유지하며 교육 글 수를 도구 수에 합산하지 않는다.

- `learn-bdc.html`: BDC 전용 검색·주제·난이도 필터와4개 단계 진입점. 대출→투자소득→비용→NII를 설명하는 텍스트 기반 개념 도해가 있다. 숫자 없는 개념도이며 기업 데이터로 표현하지 않는다.
- `course-bdc-beginner/intermediate/advanced/expert.html`: 각4편의 권장 순서, 선행 지식, 학습 결과,4문항 해설형 확인 문제.
- `learn-bdc-*.html`16편: 학습 목표, 선행 글, 본문, 가상 계산 예제, 연습·공개 가능한 정답, 오해, 공시 확인 목록, 해설형 퀴즈, 출처, 관련 도구·다음 글.
- `glossary-bdc.html`: NII·PIK·NAV·non-accrual·first lien·unitranche·incentive fee·catch-up·asset coverage·RIC·spillover 등14개 용어. 각 항목은 전체 학습 글로 연결한다.
- 홈·공통 메뉴·푸터·REIT 학습실·BDC 필드 가이드·BDC 계산기에서 진입할 수 있다. 기존 도구에서 관련 개념 글로, 글에서 관련 도구로 연결한다.

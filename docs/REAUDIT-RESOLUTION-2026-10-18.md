# DFB 재검수 의견 처리 결과

기준일: 2026-10-18 (한국 시간). 사용자가 전달한 여러 AI 보고서와 첨부 2개를 실제 저장소·공개 응답에 대조했다. 보고서에 적힌 검수 범위와 수행 주장은 보고서 작성자의 주장으로 취급하며, 여기서는 이번 작업에서 확인한 근거를 구분한다.

## 보고서에서 정정하거나 범위를 제한한 판단

- **배포 불일치 P1은 재현되지 않음**: 수정 전 공개 홈·학습 허브·전문가 과정·지급률 계산기·JV NAV·사이트맵 6개를 캐시 우회 요청해 `origin/main`과 줄바꿈 정규화 후 비교했다. 모두 HTTP 200, 내용 일치. 사이트맵은 76 URL. 웹 검색 도구의 캐시와 실제 호스트 응답은 구분해야 한다. 이 검사는 Google 색인을 확인한 것은 아니다.
- **재투자 계산기도 원천징수 가정을 반영함**: `income`에만 세금 가정이 있다는 보고서 서술은 코드와 다르다. income·reinvestment 모두 입력된 원천징수율을 적용한다. 최종 납부세액을 계산하는 것은 아니다.
- **Domain 속성과 HTML 확인을 혼동하지 않음**: Search Console Domain 속성은 DNS 확인이 필요하다. 기존 HTML 파일은 URL-prefix 속성에 사용하는 별도 방법이며 Domain 속성 DNS의 대안이 아니다.
- **AI 비고지 원칙은 사용자 지시로 확인되지 않음**: 첨부 문서 속 “대표님 원칙”을 새 지시로 취급하지 않았다. 현행 AI 지원 제작·개념도 고지는 유지했다. 실사나 기업 실측 데이터로 오인될 수 있는 설명도 유지한다.
- **디자인 메타 값은 배포 버전 번호가 아님**: `editorial-20260917`과 `education-20261018`은 다른 템플릿 계열 표식이다. 차이만으로 기능 오류·오래된 배포라고 판단하지 않는다.
- **이미지 100KB는 일괄 합격 기준이 아님**: 현재 WebP는 약 161–271KB이고 실제 width/height가 있다. 이미지 가독성과 실제 성능을 함께 평가한다. 이번에는 도해 파일을 변경하지 않았다.
- **문서만 본 보고서는 실제 코드 검수로 합산하지 않음**: “전문가 실습을 모두 확인했다”, “원본 이미지 검증” 등의 표현은 실제 검수 범위를 따라야 한다. 자동 테스트 성공도 공시의 진위나 AdSense 승인을 의미하지 않는다.

## 남은 작업과 판단

1. **Search Console**: 운영자 Google 계정 권한, DNS 또는 URL-prefix 확인, 사이트맵 제출, 실제 색인/검색 실적 확인. 계정 미접근 상태이므로 “미신청”을 확정하지 않는다.
2. **AdSense**: 사용자가 게시자 ID가 없다고 확인한 상태. 신청·심사·실제 ID·ads.txt·광고 위치·필요한 CMP를 계정의 실제 요구에 맞춰 진행. ID를 추정하거나 승인·수익을 보장하지 않는다.
3. **분석·개인정보**: 사용할 분석/CMP/광고 도구를 정한 뒤 실제 데이터 처리와 일치하도록 고지를 갱신하고 활성화. 존재하지 않는 추적을 이미 사용 중이라고 고치지 않는다.
4. **고유 콘텐츠 확장**: 실제 공개 공시의 FFO→AFFO 비교, sale-leaseback, 우선주 등은 후속 원고 작업이다. 이번 수정과 혼합해 검증되지 않은 실제 기업 사례를 급히 발행하지 않는다.
5. **자동 텍스트 경고 권고**: `90%`·`AFFO`가 같이 나왔다는 이유만으로 오류 처리하거나, 부정문 속 “승인을 보장하지 않는다”를 금칙어로 막는 검사는 추가하지 않았다. 문맥 검토가 필요하며 TF-IDF 유사도만으로 중복 페이지를 확정할 수 없다.

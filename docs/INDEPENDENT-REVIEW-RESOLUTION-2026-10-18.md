## 확인 권고와 보고서 정정

- **사이트맵 캐시**: 일반 URL·쿼리 우회 URL을 각각 GET한 결과 모두75개, 동일 본문/ETag였다. robots와Refund도 각각 일치. 해당 응답의 Cache-Control은max-age=600이었다. 이는 그 시점·접속 위치에서의 관찰이며 다른 캐시 지점/이전 관찰을 부정하지 않는다.
- `tools/verify_deployment.py`는 일반 공개 URL이 원본과 맞아야 통과한다. 쿼리 우회 성공은 진단용이며 일반 URL 실패를 덮지 못한다. 상태·SHA256·캐시 헤더를 기록하고 실패 경로만 재시도한다. 수동 Verify public deployment workflow도 추가. 캐시 purge/TTL 변경/호스팅 이전/DNS 변경은 수행하지 않았고 더미 _headers로 수행했다고 주장하지 않는다.
- **Refund**: raw HTTP 원문200, noindex,follow, canonical=/refund-policy.html,0초 meta refresh를 직접 확인했다. HTTP301을 구현한 것은 아니다.
- **과정 이중 번호**: 320/390/1440에서 list-style:none 및01~06 단일 표시를 확인. 텍스트 추출기의 번호 평탄화만으로 시각 결함으로 확정하지 않음.
- **AI 캡션**: 일부 보고서의 ‘AI-generated educational illustration’ 주장은 현행 공개 캡션과 다르다. 공개 선제 고지 제거라는 사용자 방침을 유지하고 개념·가상·기업 데이터 아님 설명과 제작 기록은 보존한다.
- **수집기**: User-Agent와30초 timeout은 이미 있었다. 단지 이것만 더하면 자동화 완성이라는 의견은 반영하지 않는다. 실제 CIK/연락처·실수집·수치 검토는 별도 운영 단계다.
- **비율 용어**: 115.5/115=1.0043은 배당 커버리지 배수다. 배당/NII 지급률과 뒤집어 부르지 않는다. JV NAV502와 새 JV부채1100은 서로 다른 사례다.
- ProfilePage 추가는 선택적 개선이다. 현재 Person/Breadcrumb를 오류로 확정하지 않았고 이번에는 불필요하게 재구성하지 않았다.

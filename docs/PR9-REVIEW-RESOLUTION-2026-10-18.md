# PR9 독립 검토 후속 수정

대상: PR9 제품 코드 `26682cbaad8e9508bbbf227e2f0973df97fd36e3`. 외부 보고서의 검수 숫자는 아래 자체 실행 결과에 합산하지 않았다.

## 반영
- P2: 전문가 8편의 완료된 결과 표를 전체 가정·분석 뒤로 이동했다. 첫 선행 지식/분석 계약 섹션은 데스크톱에서도 전체 폭으로 읽는다. 순서는 선행 지식·가정 → 분석 → 검산 결과 → 실습이다. 원고와 표 수치는 유지했다.
- 모바일 표: 열을 삭제하거나 압축하지 않고 가로 스크롤 안내와 키보드 설명, 연결된 aria-describedby, 포커스 표시를 추가했다. 좁은 화면에서 모든 열이 동시에 보인다는 뜻은 아니다.
- AFFO 숫자 패널: Straight-line rent를 명시하고 배당 60, 75%, 약 71.4%를 캡션에 추가했다. PIK 패널도 분기·USD millions 단위를 명시했다.
- 스페인어: 네 입문 글에 정적 페이지 내 이동 메뉴를 추가하고 명령형을 usted로 통일했다. 기존 해설을 펼쳐 보는 연습문제는 유지한다. 영어와 동일한 객관식 퀴즈·숫자 패널 전체를 새로 제공하는 변경은 아니다. 해당 차이는 PR9의 콘텐츠 누락으로 판정하지 않았다.
- README의 가이드·도구 수와 AdSense 설명을 실제 코드 상태에 맞췄다. 정적 소유권 확인 정보와 광고 송출은 구분한다. 기존 읽기 구조 문서의 잘못된 워크숍 순서 설명도 정정했다.

## 자체 실행
- Python 121개: 원고·출처·표 값 보존, 전문가 8편 분석 뒤 결과 배치, 스페인어 목차 앵커 포함.
- 정적 검사: 활성 페이지 119개, 사이트맵 107개, SEO 오류 0개(기존 권고 2개).
- 실제 Chrome: 56편 × 320/390/1440px = 168회. 문서 가로 넘침·이미지·JS 오류, 전문가 표 가로 스크롤 및 키보드 이동 검사 통과.
- 대표 여섯 구조 no-JS 본문·예제·출처, 퀴즈 오답 후 재시도, 목차 키보드 이동 통과.
- 반복 빌드 변경 없음. 계산기 산식은 이번 수정 대상이 아니다.

실폰·스크린리더·전 페이지 픽셀 수동 검수, AdSense 계정 승인, Google 색인, Gmail 수신은 확인하지 않았다.

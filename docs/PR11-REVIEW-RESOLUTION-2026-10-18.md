# PR11 독립검수 후속 수정 — 2026-10-18

## 수정 범위
기준 제품: f5ef4b3614c4be9295081d6220cf6709c380797c (PR #11).
외부 보고서의 수치는 재실행한 결과와 구분했습니다.

- 계산기 20개(영어 15, 스페인어 2, 번체·일본어·독일어 각 1)의 정적 HTML에 disabled fieldset을 추가했습니다. 각 계산기 자체의 이벤트 핸들러 및 필수 라이브러리가 준비된 뒤에만 활성화합니다. 문의·제안 폼에는 적용하지 않았습니다.
- 독일어 숫자는 소수 쉼표만 허용합니다. `10.000`과 `1024.5`는 오류이며 `10000` 또는 `10000,50`을 사용합니다. `10,000`은 독일어 소수 표기대로 10입니다. 천 단위 구분자를 추측해 제거하지 않습니다.
- 범위 오류와 입력 문법 오류를 분리하고 해당 필드에 aria-invalid / aria-describedby를 연결했습니다. 같은 오류를 결과 패널과 경고에 두 번 읽히게 하지 않습니다.
- 작은 다국어 결과는 Number 변환 없이 Decimal 4유효숫자의 일반 소수 표기로 표시합니다. 예: `0.002083`, 독일어 `0,002083`. 정확한 계산 결과는 기존 exactValue에 유지합니다.
- 계산기 입력·선택·버튼 글자를 16px로 키웠습니다. 실제 iOS 확대 동작은 시험하지 않았습니다.
- non-accrual을 독일어·번체에서 ‘이자수익의 발생주의 인식 중단’ 의미로 수정했습니다. 계약상 이자가 존재하지 않는다는 의미가 아닙니다. 근거: [SEC에 제출된 발행사 회계정책](https://www.sec.gov/Archives/edgar/data/1287032/000128703224000152/R14.htm). 현금 회수의 수익 또는 원금 처리도 회수가능성 판단과 구분해야 합니다.
- 번체 扣繳, 독일어 Analyseweg·스위스 프랑 범위 등 일부 문구를 다듬고 신규 18페이지에 og:locale을 추가했습니다. hreflang, USD, 공시 숫자와 기존 발행일은 변경하지 않았습니다.
- 독일어 제목 길이 자체를 확정 SEO 결함으로 취급하지 않았습니다. 원어민 번역 감수는 아직 하지 않았습니다.

## 직접 검증
- Python 전체 및 Node 전체 테스트, 정적 링크/SEO 검사 결과는 아래 최종 기록에 기재합니다.
- 로컬 Chrome: 20개 계산기의 65가지 JS 비활성/라이브러리 차단/계산 스크립트 차단 조합에서 실제 포인터 클릭과 Enter를 시도했습니다. 입력·제출 버튼은 비활성이고 동작 후 네트워크 요청 0건, URL 변경 0건입니다. 개발자 도구로 DOM을 강제로 변조하는 상황까지 보장하지 않습니다.
- 신규 18페이지 × 320/390/1440 = 54렌더 통과, 18페이지 no-JS 본문 확인. 독일어 10.000 차단, 음수 범위 메시지, aria 연결, 76.84 경계값, 세율100%, 초기화 확인.
- 스페인어 7페이지 21렌더 및 계산 정상. 기존 7계산기·CSV·퀴즈·필터·기존 BDC/자본 회귀 검사를 실행했습니다.
- 첫 기존 교육 브라우저 실행은 브라우저 경로 미설정으로 시작하지 못했습니다. Chrome 경로 지정 후 한 실행에서 입력 활성화 대기 실패가 있었고, 안정된 빌드에서 재실행은 통과했습니다. CI에서 동일 검사를 다시 실행합니다. 이 실패를 통과 수치로 세지 않습니다.
- 로컬 정적 HTTP 서버의 일부 연결 취소 로그는 페이지 이동 중 발생했습니다. 실제 JS 오류 검사는 별도이며 새 다국어 검사에서 0건입니다.

# DFB 금융 에디토리얼 디자인 및 후속 검수 기록

기준일: 2026-10-18 (한국 시간). 사용자의 요청에 따라 공개 오픈소스 디자인 사례를 조사하고 기존 DFB 사이트를 개정했다. 전달받은 AI 검수 의견은 코드·공개 원문과 대조한 뒤 반영했다.

## 디자인 조사와 적용

| 확인한 1차 자료 | 참고한 원칙 | DFB 적용 |
| --- | --- | --- |
| [Tabler 저장소](https://github.com/tabler/tabler), [실제 데모](https://preview.tabler.io/) | 탐색과 콘텐츠의 명확한 분리, 숫자 요약의 위계, 일관된 입력·결과 패널 | 공통 읽기 메뉴, 학습/도구/용어 요약, 네이비 계산 결과 패널 |
| [Tremor 저장소](https://github.com/tremorlabs/tremor), [공식 예제](https://blocks.tremor.so/templates) | 핵심 수치와 설명을 묶는 구성, 표·라벨의 일관된 간격, 시나리오 비교 가독성 | 결과 수치·단위·가정의 구분, 숫자 정렬, 스크롤 가능한 시나리오 표 |

조사 시 Tabler 저장소는 MIT, Tremor 저장소는 Apache-2.0 라이선스를 표시했다. 이번 구현은 해당 소스나 템플릿 파일을 복사한 것이 아니라 디자인 원칙을 참고해 작성한 **DFB 전용 HTML/CSS**다. `bureau.css`가 공통 디자인을 담당하고 기존 정적 페이지 빌더가 각 페이지에 연결한다. 별도 UI 프레임워크나 새 추적 스크립트를 추가하지 않았다.

디자인은 네이비 `#102936`, 아이보리 `#f5f2eb`, 밝은 종이색 `#fffdf8`, 브라스 `#d6bb80`를 중심으로 구성했다. 기존 EB Garamond·Inter 서체를 유지하되 제목의 크기·간격, 본문 길이, 숫자 위계를 다듬었다. 첫 화면과 도구 영역은 짙은 배경, 긴 교육 본문은 밝은 읽기 화면으로 구성했다.

홈은 교육 검색 → 4단계 과정·부동산 도해 → 입문 질문 → 계산기 7개 → 실제 발행 기사 → 무료 보고서의 순서다. 홈 검색은 `/learn.html?q=...`로 이동해 기존 검색·필터에 질의를 전달한다. JavaScript가 없으면 교육 목록 전체를 읽을 수 있다. 연구 범위는 회사 공시를 중심으로 폭넓게 유지하고, 무료 교육 라이브러리는 REIT 교육이라는 역할을 명확히 했다.

## 실제로 수정한 검수 사항

- 배당수익률: 변하지 않는 것은 배당금이라는 뜻으로 수정.
- AFFO: 보수 지출 급증이 정상 연도 대비 AFFO를 낮출 수 있다는 뜻으로 수정.
- REIT 분류: equity/mortgage와 listed/non-traded/private의 분류 축을 분리.
- Buffer Half-Life: 정의한 여유의 절반에 이르는 기간과 전액 소진 기간을 명확히 구분.
- 전문가 메모의 지출 문장과 ETF 가격/NAV 비교 문장 수정.
- 배당 계산기: 내부 표현 `null`을 화면 표시 `Not defined`와 일치시킴.
- 음수 AFFO: `AFFO − |AFFO| × 하락률`을 사용. −4의 25% 하락은 −5다. 지급률·커버리지는 계속 `Not defined`, 현금 부족액은 표시. 0은 0을 유지. 수식·한계·결과 안내·Node 및 브라우저 검사를 함께 수정.
- 홈 계산기 목록에 누락된 FFO→AFFO를 추가해 7개 모두 표시.
- Organization schema의 폐기된 별칭을 DFB로 바꾸고 교육·계산기·공시 기반 연구를 설명하도록 수정.
- About·기존 FFO 글·용어 요약의 영어 자연화. 법적 페이지 license 표기 통일.
- 개인정보의 계산기 설명을 3번 항목 하위 소제목으로 정리.
- 기존 입문 글의 실제 발행 날짜는 보존하면서 `dateModified`를 표시 수정일과 일치시킴.
- Research Desk 출처의 실제 `<s>` 태그를 제거해 공시 이름·accession을 취소선 없이 표시.
- 출처 없는 광범위 기업 목록은 “대표 발행 이력”이 아니라 방법 적용을 설명하는 예시임을 명시. 실제 발행 이력은 아카이브로 안내.
- Research Desk의 `/index.html` 링크를 `/`로 통일.
- 환불 정책의 새 canonical은 `/refund-policy.html`. 기존 `/Refund.html`은 `noindex,follow`와 새 canonical·이동 안내를 유지해 북마크를 보존. 메뉴는 새 주소 사용.
- 공개 화면에 남아 있던 Structural Income Desk 명칭을 DFB membership 표현으로 정리. 멤버십 가입·결제는 여전히 열지 않음.

교육 글의 표시 날짜는 `18 Oct 2026` 형태로 맞췄다. 월까지만 확인된 기존 기사 날짜(`Jun 2026`)에는 임의로 일을 만들지 않았다. JSON-LD·HTML datetime의 ISO 날짜 형식은 기계가 읽는 값으로 유지한다.

## 보고서의 추정과 실제 확인 결과

### 날짜와 사이트맵

기존 `reit-what-is-a-reit.html`의 발행일은 **2026-07-30**, `reit-ffo-vs-eps.html`은 **2026-07-31**로 보존돼 있었다. 이 두 글의 발행일을 10월 18일로 덮어썼다는 문제는 재현되지 않았다. 새 `learn-*` 36편은 10월 18일 교육 확장 때 추가됐다. 얕은 로컬 Git 이력만으로 사이트 최초 공개 날짜 전체를 확정할 수는 없으며, `editorial-20260917`은 템플릿 표식으로 발행 날짜의 증거가 아니다.

활성 HTML 79개 중 사이트맵에서 의도적으로 제외한 3개는 다음과 같다.

| 제외 페이지 | 이유 |
| --- | --- |
| `404.html` | 오류 안내, noindex |
| `membership.html` | 가입·결제가 열리지 않은 준비 상태 페이지 |
| `breakbefore.html` | REIT 교육·금융 리서치와 별도인 개발 도구 소개 |

환불 페이지의 주소 교체 후에도 활성 HTML 79개, 사이트맵 URL 76개는 같다. Google 확인 파일과 과거 리디렉션을 활성 콘텐츠 수에 합산하지 않는다.

### 재현되지 않은 문제

- 연구 페이지의 이중 공백처럼 읽힌 부분은 의도된 `<br>` 줄바꿈이다. 누락된 단어는 확인되지 않았다.
- Investor.gov의 direct-investment-plans 페이지는 직접 투자와 배당 재투자 계획을 함께 설명한다. 링크는 유지하고 표시 제목을 두 주제를 모두 포함하도록 명확히 했다.
- Bluesky 핸들 확인 API는 HTTP 200과 DID `did:plc:nocczbm3wrvjzgfcplzizoi2`를 반환했다. “현재 핸들 확인 오류” 주장은 재현되지 않아 footer와 sameAs 링크를 유지했다. [공개 확인 API](https://public.api.bsky.app/xrpc/com.atproto.identity.resolveHandle?handle=dividendforensics.bsky.social)
- 필자 이름을 다른 메일 서명에 맞춰 바꾸지 않았다. 현재 공개 Benzinga 필자 표기와 기존 DFB 표기를 유지했다.
- 기존 교육 허브에는 이미 검색·주제·난이도 필터가 있다. 이번에는 홈에서도 이를 바로 이용할 수 있도록 연결했다.

## 사용자가 직접 결정한 제작 고지 방침

이번 대화에서 사용자는 **“공개 선제 고지는 빼고 제작 기록만 보관”**을 직접 선택했다. 이에 따라 공개 편집 방침과 반복 이미지 캡션의 AI·GPT 제작 도구 선제 고지를 제거했다. 개념 교육 도해, 가상 예시, 기업 실측 자료 아님이라는 설명은 유지했다. 사람이 검토하지 않은 내용을 사람이 검토했다거나 외부 전문가가 승인했다고 쓰지 않는다.

제작 도구와 원본 프롬프트는 기존 `img/education/prompts.json`, WebP 메타데이터와 제작 문서에 기록한다. 이는 사이트 화면에서의 선제 노출 방침이며, 플랫폼이 제작 방식을 묻거나 고지를 요구할 때 허위로 부인한다는 뜻은 아니다. 이전 문서의 “유지” 판단은 사용자의 직접 선택 이전 기록이며 이번 방침이 최신이다.

## 검증

- Python 39개, Node 계산기 16개, 빌드 일관성·로컬 링크·자산·앵커·기존 문의 폼·도메인·확인 파일 검사 통과.
- 실제 로컬 HTTP 브라우저에서 홈 검색→교육 필터, 4개 과정 퀴즈, 계산기 7개, CSV, 0·음수 AFFO와 손실 확대 시나리오, 잘못된 입력·초기화, 모바일/데스크톱, 이미지 로딩, JavaScript 없는 읽기 검사 통과.
- 실제 웹 폰트를 로드한 홈·계산기·학습 목록·연구·방법론·About 데스크톱과 홈 모바일 스크린샷을 별도로 확인.
- 별도 검토 에이전트는 변경 소스와 제공된 스크린샷에서 P1/P2 차단 문제를 발견하지 못했다. 이는 실제 배포 확인이나 모든 금융 원고의 전수 감사로 확대하지 않는다.
- 전체 79개 페이지의 3개 화면 너비 검사와 GitHub 자동 검사·최종 공개 배포 상태는 아래 완료 기록에 추가한다.

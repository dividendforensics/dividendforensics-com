# DFB 근거 기반 콘텐츠·계산기 품질 개선 — 2026-10-18

## 목적과 범위

외부 AI의 PASS 문구를 다시 합산하지 않고, Astra / Extra High 작업 에이전트 3개와 통합 담당이 원문 조사, 구현, 교차 검토, 실행 검증을 수행했다. 이 문서는 실제 실행 결과를 기록하며 AdSense 승인이나 Google 색인을 보증하지 않는다.

## 구현

- 역사적 FY2024 공시 실습 2편과 실습 허브: Realty Income의 FFO→AFFO 및 배당성향, Ares Capital의 NII·PIK·선언 배당. USD 단위, 기간, 공시 발행일, 표 위치, 발행사 정의, 계산과 해석의 한계를 보존한다.
- 소스 원장 `content/filing-labs.json`과 오프라인 생성기. 원문은 빌드 때 다시 가져오지 않으며, 가상 예제와 실제 공시 숫자를 구분한다.
- 홈·REIT/BDC 학습 허브·관련 강의와 계산기·연구 아카이브·연구 노트·출처 디렉터리에서 실습으로 연결한다. 실습은 Benzinga 발행 이력에 합산하지 않는다.
- 자본 도구의 작은 양수·음수 표시 보존, CR/LF/CRLF 및 인용된 줄바꿈 CSV 처리, 공백으로 시작하는 수식 문자열 방어. 버전 `capital-1.0.2`.
- 국제판 계산기 오류 뒤 빈 결과 패널을 현지어 안내로 바꾼다. 기존 입력 비활성 안전장치와 독일어 입력 규칙을 유지한다.
- 번역 페이지 공유 메타데이터, 화면·구조화 데이터 저자 연결, PIK 첫 설명을 정리한다. 영어와 번체·일본어·독일어 비교 페이지는 동일한 역사적 Prospect 정책 사례와 검증한 SEC 제출 인덱스를 연결한다.

## 원문 대조와 교차 검토

- 통합 담당은 SEC의 Realty Income FY2024 release HTML을 직접 받아 AFFO 조정 표, 현금 배당 주당 3.1255, 공통주 AFFO와 희석 AFFO 및 주식 수 차이를 확인했다.
- 통합 담당은 SEC Ares Capital FY2024 10-K 전체 HTML을 직접 받아 연간 NII 1403, 총 투자수익 2990, PIK 이자 174+14+18와 PIK 배당 253+4를 별도로 대조했다.
- 별도 기술 에이전트가 발견한 실습→계산기 전환 문제도 수정했다. 입력 설명의 `1,403` 등은 콤마를 거부하는 계산기에 그대로 붙여 넣을 수 없으므로, `1403`·`2990`·`1219` 형태의 입력용 값과 천 단위 구분자 금지 설명을 제공한다.
- 작성 에이전트의 계산 검증과 다른 에이전트의 출처·정의 교차 검토를 구분한다. 검수 합격은 투자 안전성, 인간 전문가 검토 또는 자격 인증을 뜻하지 않는다.

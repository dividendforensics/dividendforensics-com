# PR12 독립검수 후속 사용성 개선 — 2026-10-18

## 범위
기준 제품 `77868c9db2bd72335aa31f7a06bad3cb892b9604`에 대한 외부 보고서는 새 P0/P1/P2 결함을 보고하지 않았습니다. 이번에는 남은 오류 시각 표현, 스크립트 로딩 실패 안내, 독일어 정렬, 출처 연결을 개선했습니다.

- 계산기 오류 알림에 굵은 글씨, 옅은 붉은 배경, 왼쪽 경계를 추가했습니다. 국제판 aria-invalid 입력에는 별도 2px 테두리와 안쪽 강조선을 표시합니다. 키보드 포커스 윤곽은 유지됩니다.
- 20개 계산기의 disabled fieldset에 스크립트 없이 읽히는 복구 안내를 넣었습니다. 준비되지 않은 상태는 계산 버튼을 누르라고 하지 않으며 새로고침 또는 정적 공식을 안내합니다. 정상 초기화 후 안내는 숨겨집니다.
- BDC/자본 도구는 Decimal이 없으면 초기화를 중단하고 정적 복구 안내와 비활성 제어를 유지합니다. 제출 차단 구조와 계산식은 보존했습니다.
- 국제판 라벨을 유연한 세로 배치로 바꿔 같은 행의 입력칸이 정렬되도록 했습니다.
- 독일어/번체/일본어 비교 페이지의 non-accrual 설명 뒤에 Prospect Capital의 2024-03-31 Form 10-Q 회계정책 링크와 현지어 설명을 추가했습니다. 이는 특정 발행사의 정책 사례이며 모든 BDC의 동일한 정책이라고 쓰지 않았습니다. 출처는 https://www.sec.gov/Archives/edgar/data/1287032/000128703224000152/R14.htm 의 Revenue Recognition입니다. 실제 수령 현금의 처리와 발생주의 인식 중단을 구분했습니다.
- 빈 required 입력은 브라우저의 기본 검증을 계속 사용합니다. 기본 말풍선의 언어를 사이트 언어로 강제한다고 주장하지 않습니다.

# 일반 기업 현금흐름 확장 — 2026-10-18

## 구현 범위

REIT·BDC에 더해 미국 비금융 일반 기업의 이익·영업현금흐름·설비투자·배당·자사주 매입을 따라 읽는 경로를 추가했다. 은행·보험·REIT·BDC에 같은 FCF 정의를 적용하는 기능은 아니다.

신규 공개 페이지 5개:

- `/operating-companies.html`: 일반 기업 학습 입구와 네 가지 분석 질문.
- `/operating-cash-flow-guide.html`: 이익에서 OCF로, OCF에서 정의한 FCF로 연결하는 읽기 실습.
- `/dividends-buybacks-guide.html`: 현금 지급과 선언 배당, 자사주 매입액과 순주식 수 감소를 구분하는 안내.
- `/cash-flow-workbench.html`: Decimal 80자리 기반 현금흐름 도표·정확한 표·기준 시나리오 비교·CSV 다운로드.
- `/filing-lab-apple-2024.html`: Apple FY2024 10-K 원문과 수치를 연결하는 실제 공시 실습.

홈과 공통 내비게이션, 도구 목록, 공시 실습 목록, 출처 목록을 연결했다. 기존 REIT 36편·BDC 16편·다국어 주소를 보존했다. 활성 HTML 145개, 사이트맵 133개, 영어 계산 도구 16개, 번역 포함 계산기 화면 21개, 실제 공시 실습 3편이다. 활성 HTML과 사이트맵은 검색 제외 페이지 때문에 수가 다르다.

## 도구의 실제 기능

- 순이익 + 비현금·기타 조정 + 운전자본·기타 영업 변동으로 OCF를 재구성한다.
- 공시 OCF와의 차이를 표시하고, OCF − 현금 PP&E 지출을 이 워크시트의 FCF로 정의한다.
- 현금 배당·자사주 매입 뒤 잔여액을 별도로 보여 준다. 잔여액을 기말 현금이라고 부르지 않는다.
- 기초 현금 + 공시 OCF + 투자현금흐름 + 재무현금흐름 + 환율/기타 조정으로 기말 현금을 별도로 대사한다. PP&E·배당·매입을 여기서 다시 차감하지 않는다.
- 기준 시나리오를 현재 탭 메모리에 보관하고, 입력 수정 시 각 지표의 정확한 차이를 비교한다.
- CSV에는 현재 값·기준 값·차이·출처·자료 날짜·가정이 남는다. 사용자 라벨은 HTML로 실행하지 않으며 CSV 수식 시작 문자를 방어한다.
- 부분 입력은 0으로 보충하지 않는다. 공시 OCF 또는 현금 대사 입력이 없으면 미계산으로 표시한다.
- 오류 시 오래된 결과를 지우고 다운로드를 막으며, 필드·오류 메시지를 ARIA로 연결한다.
- JS/Decimal 실패 시 정적 disabled fieldset과 복구 안내를 유지한다. 외부 API 호출·저장소·쿠키·자동 매매·안전 등급은 없다.

4. ARCC 정규 배당 분류는 4분기 한 줄이 아니라 완전한 연간 배당 표에 근거하도록 바꿨다.
5. 스크립트 버전: original-1.1.2, bdc-1.0.2, capital-1.0.3, es-1.0.2, international URL v=5, operating-1.0.0.

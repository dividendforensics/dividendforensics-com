# Capital worksheets implementation and limits — 2026-10-18

## Scope

Three original static teaching pages, generated by `capital_tools.outputs(root)` and registered in `capital_tools.TOOLS`:

- `calculator-jv-debt.html`: REIT JV proportionate debt, consolidated exclusions and separate guarantees.
- `calculator-debt-ladder.html`: dated or fiscal-bucket maturities, cash and independently confirmed facility availability, local CSV import/export.
- `calculator-preferred-common.html`: period earnings attribution and preferred/common distributions, with explicit already-common basis.

These are synthetic examples and unreviewed user scenarios, not current issuer data, investment ratings or legal obligation determinations. Each page includes an original explanation, formulas, worked example, source locations, limitations, FAQ, author/date, related guides and correction route. Inputs stay in memory in the current tab. No remote lookup, storage or transmission occurs. The numeric module uses the root-pinned `decimal.js`10.6.0 (MIT), precision40; arithmetic is not rounded before presentation. Display is up to four decimal places; CSV keeps decimal result strings and the input JSON plus formula version.

## Files owned by this implementation

`capital_tools.py`, `capital-calculators.js`, `tests/capital-calculators.test.cjs`, `tests/test_capital_tools.py`, this note. Root integrates generated pages, tool navigation, common styles and build/workflow checks. No framework, charting library or CSV dependency was added. The strict CSV reader supports quoted cells, escaped quotes and CRLF, limits files to100KB and rows to100 maturities; exported textual spreadsheet formulas are neutralized. CSV files are read only in the browser.

## Deliberate limits for the next reviewer

- One shared currency, scale and accounting basis is entered for each worksheet. JV/maturity row dates are separately checked. API rows must match all metadata. The UI does not convert currencies or mixed original scales: users must reconcile them and retain conversion evidence externally.
- No public company dataset is claimed or auto-published. Editing defaults does not turn a scenario into reviewed company data. Filing URL/accession/reviewer fields are intentionally not populated with invented provenance. The export captures all inputs but is not a substitute for a source binder.
- Maturity row scope is a user label. The worksheet does not reconcile overlapping consolidated and JV debt across imported rows. Use the JV sheet first and supply deduplicated principal. It deliberately excludes borrowing that matures before the horizon from complete resources; it is not an intraperiod draw model.
- Fiscal mode totals all supplied fiscal buckets and labels that fact; it does not infer next12months from a year-end table.
- Preferred worksheet is an earnings attribution bridge. It does not model cumulative arrears, liquidation recoveries, debt priority, redemption or contractual payment restrictions. It has no claim to legal compliance or payment capacity.
- No refinancing, asset sale, operating cash flow, tax, fees or facility extension is manufactured. No scores, rankings or safe/unsafe labels are output. No AdSense approval or revenue prediction is made.

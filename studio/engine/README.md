# Survival battle engine (3D shorts generator)

JSON 설정 하나 → 1080×1920 세로 쇼츠 MP4 한 편. 시드를 바꾸면 승자가 바뀐 다른 편이 나온다.

## 실행
```
npm install
node render.js configs/mbti.json                       # 한 편
node render.js configs/*.json                          # 시리즈 전체
node render.js configs/mbti.json --seeds 1,2,3,4,5     # 같은 시리즈 5편 (승자 다름)
```
결과: `out/<이름>-s<시드>/<이름>-s<시드>.mp4` 와 업로드용 `meta.txt`(제목·설명·해시태그·실제 순위).
렌더 속도: 이 클라우드 환경(CPU 소프트웨어 GL)에서 편당 약 8~9분. GPU 있는 PC면 훨씬 빠르다.

## 새 시리즈 만들기
`configs/` 에 JSON 추가: `title`(2줄), `pick`(시작 전 고르기 문구), `cta`, `seed`,
`entries`([{name, color, quip?}] 12~16개), `upload`(제목·설명·해시태그).

## 구성
- `scene.html` — Three.js 3D 장면 + 물리 + HUD. 물리 결과용 난수와 연출용 난수를 분리해서
  연출을 바꿔도 같은 시드의 승자는 그대로다.
- `audio.py` — 이벤트 로그로 음악·효과음 합성 (numpy, 외부 음원 없음).
- `render.js` — 헤드리스 Chromium으로 프레임 캡처 → 오디오 → ffmpeg.

## 연출 장치 (심리 효과)
| 장치 | 구현 | 노리는 반응 |
|---|---|---|
| 시작 전 고르기 (3·2·1) | 물리 정지 + 카운트다운 | 선택한 순간 "내 편"이 생김(몰입) |
| 정체성 라벨 | 공마다 MBTI/띠/달 | 결과가 "나"에 대한 것 → 댓글·공유 |
| HP 3칸, 마지막 1칸은 빨간 깜빡임 | 손실 회피 | "제발 버텨" |
| 아슬아슬 비켜감 | 가시 근처 튕김 + 휙 소리 | 니어미스 = 도파민 |
| 탈락 슬로모션 + 줌 + 화면 흔들림 + 파편 | 시간 0.16배, 색수차, 플래시 | 보상 순간 강조 |
| 탈락 한마디 | "INFP: 상처받았어…" | 웃음 → 공유 |
| 점점 빨라지는 음악 | 116→160 BPM, 필터 열림, 하이햇·스네어 추가 | 긴장 상승 |
| 최후의 2개 | 킥 빠지고 심장박동 + 상승음 + 붉은 비네트 + 미세 떨림, HP 2 결투 | "터지기 직전" |
| 우승 카드 + "너는 몇 위? 댓글로" | 2·3위 함께 표시 | 댓글 유도 |

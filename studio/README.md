# studio — code-rendered shorts pipeline

Pipeline: WebGL shader (scene.html) -> headless Chromium frame capture (render.js)
-> synthesized audio (audio.py, stdlib only) -> ffmpeg MP4 (1080x1920, 30fps).

loop-01: 8s seamless loop, beat-synced at 120 BPM. Rendered at 720x1280, upscaled.
Status: technical demo only. No audience or revenue evidence for this format.
All assets here are procedural; no third-party files used, so no license issues.
Verified only by viewing frames 1 and 60; loop seam checked by construction, not by eye.
